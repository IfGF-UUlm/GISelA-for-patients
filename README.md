# GISelA for patients

This repository contains the code accompanying the paper "Few-Shot Prompting in Large Language Models Yields Expert Quality Translations of Outpatient Reports into Patient-Friendly Language: A Blinded Comparative Evaluation"
The code is provided for transparency and inspection purposes. However, due to restrictions imposed by the local ethics committee, we are not permitted to share patient data. As a result, the code in this repository cannot be executed end-to-end.

## Repository Structure

The repository consists of three Jupyter notebooks:
- [`01_letters.ipynb`](./01_letters.ipynb): Preprocesses the translated outpatient reports and prepares the data for downstream analysis.
- [`02_analysis.ipynb`](./02_analysis.ipynb): Performs the statistical analysis and evaluation of the translation outputs.
- [`03_figures.ipynb`](./03_figures.ipynb): Generates Figure 1 as presented in the paper.

### Notes
While the full pipeline cannot be reproduced without access to the underlying data, the notebooks document the methodology and analysis steps used in the study.
